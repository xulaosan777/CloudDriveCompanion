智能网盘助手 (Cloud Drive Companion)
别称：智能批量脱壳与伪装封装工具

使用说明

本软件专为应对现代网盘资源常见的“防炸、和谐、误判封禁”手段而打造，是一个集“批量脱壳解压”与“批量伪装封装”于一体的综合生产力工具箱。它采用单文件绿色架构，无需在电脑上预装任何 WinRAR、7-Zip 等第三方压缩软件，双击即可直接使用。

============================================================
🌟 核心功能一览
============================================================

1. 🔓 批量脱壳解压 (资源穿透提取)：
   专门对付网盘里乱改后缀（如把压缩包后缀改成 .jpg）、多重套娃压缩（包里有包，层层嵌套）的折磨人资源。
   你只管将一个或多个文件（甚至混入文件夹）直接一把拖入软件，不管是改了假后缀还是带真正缩略图的“图种”，软件都会自动读取底层魔数特征，层层穿透、自动剥离，直接把底层真正的视频、漫画、音频或文档提取到你面前。

2. 📦 批量伪装压缩 (一键制作防炸包)：
   给资源分享者量身打造的防和谐神器。
   支持批量拖入文件/文件夹，一键为其生成具备“真图种/二进制混合、多层嵌套、随机数字混淆、文件头加密 (mhe)”的高强度防炸包。外层不仅能改后缀，更能真正显示缩略图并正常看图，网盘审查系统完全无法检测内部内容。

============================================================
🌟 技术特性与架构
============================================================
 真正的深度魔数探测与图种识别：
  不再单纯检查前几个字节。针对“伪装为带真缩略图的 JPG/PNG 图种”，软件会自动在文件前 15MB 偏移量中进行特征扫描；解压调用时强行指定格式规范，彻底突破 Windows 后缀名关联限制。
 队列流水线单线程批处理：
  采用后台任务队列架构，文件一个接一个有序处理，杜绝多任务并发争抢磁盘 I/O 导致系统假死。
 分层密码管理体系：
  兼备“全局密码”与“单文件专属密码”。支持点击表格直接呼出密码管理器，一键选用已保存的常用密码库。
 自适应高分屏现代暗黑 UI：
  原生 Windows Per-Monitor V2 DPI 渲染，字体锐利清晰。支持自由横向与纵向缩放，中间任务列表区域纵向自适应伸展。
 独立绿色纯净：
  密码配置文件保存在系统用户应用数据区，解压和压缩过程全程自动清理临时缓冲碎片。

📖 详细操作指引
============================================================

🔓 选项卡一：批量脱壳解压
专门用于对付批量伪装包与套娃包。

【输出目录】：
 留空时：各文件解压至自身所在同级父目录下的专属子文件夹中（如 "解压_文件名/"）。
 指定路径时：所有任务提取出来的文件夹将统一归拢到该指定目录下。

【全局解压密码 & 强制覆盖开关】：
 可手动输入密码，或点击“管理常用”下拉选择历史密码。
 勾选“强制覆盖应用至所有任务”时：所有任务无论自身是否配置了专属密码，均优先采用该全局密码尝试解压。
 未勾选时：优先使用每行配置的专属密码，专属密码留空时自动回退使用全局密码。

【专属密码 (表格点击设置)】：
 列表中该列呈现带下箭头的直观交互状态（如 "⚙️ [跟随全局] ▾" 或 "🔒  ▾"）。
 单击该列单元格或双击整行，即可弹出专属配置窗口，支持直接下拉调用已保存的常用密码库。

【伪装体积阈值 (MB)】：
默认为 100MB。当文件无标准格式扩展名且大于该阈值时，程序会强制将其作为伪装压缩包尝试穿透。

【终止符 (文件数>)】：
默认为 2。若解压某层后仅存在 1 个文件，程序判定依然是套娃并继续自动解压；当文件数超过设定值时，判定核心内容已释放并停止向下解压。

【添加与拖拽】：
支持随时、多次向列表中拖入文件或文件夹，也可以点击底部“➕ 添加文件...”通过弹窗多选。重复文件会自动去重。

------------------------------------------------------------

📦 选项卡二：批量伪装压缩
为分享者批量打包防炸资源而设计。

【输出目录】：
 留空时：各文件生成的压缩包存放在原文件同级父目录下。
 指定路径时：所有打包完成的防炸包集中输出到指定目录。

【套娃层数】：
指定需要嵌套打包的层数（如填 3，即完成 3 层压缩）。

【基础命名】：
 填入名称后，默认仅应用至最外层成品；内层自动采用随机三位数字（如 042）混淆视听。
 勾选“应用至所有层”后，每一层均以此名字命名。留空则默认使用源文件名。

【格式与伪装】：
 压缩格式推荐使用 .7z（具备完善的文件头加密机制）。
 伪装后缀可自由选择或手打输入（如 .jpg, .png, .pdf, .mp4）。
 追加模式：生成如 "资源.7z.jpg" 这类双后缀形式。
 替换模式 (图种)：当伪装后缀为 .jpg/.jpeg 时，程序会自动合成真实的图片文件头，生成在资源管理器中拥有真实缩略图的“真图种”防炸包。
 伪装应用至所有层：默认不勾选（仅最外层成品伪装，内层保持纯粹压缩文件以提升打包效率）。

【统一压缩密码】：
可自由输入或选用常用密码。默认不勾选“加密所有层”（程序自动执行内层保密、外层防护、中间层明文的高效防封策略）。

============================================================
📁 本地数据存储位置
============================================================
软件保存的常用密码等数据存储于系统漫游目录：
C:\Users\你的用户名\AppData\Roaming\CloudDriveCompanion\
（可按快捷键 Win + R，输入 %APPDATA%\CloudDriveCompanion 快速定位备份）。

   - 窗口支持自由弹性缩放，任务作业列表垂直自适应延展。
